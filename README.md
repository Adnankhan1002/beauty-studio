# Umra Kazmi Makeup Studio — Premium Website Demo

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173/

## Important

This version intentionally does **not** use `framer-motion` or `lucide-react`. The previous build could fail because of dependency/version mismatches during Vite dependency optimization. Animations are implemented with lightweight CSS and React state instead, so the demo has no icon or motion-package compatibility dependency.

Generated/local images are in `public/images` and can be replaced with the studio's real portfolio images later.
